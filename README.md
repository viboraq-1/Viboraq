# ViboraQ React — Phase 17

Adaptive product UI: professional dating website on desktop and mobile-first dating app on phones.

## Run

npm install
npm run dev

## Design goals

- Desktop: full-width cinematic dating website, controlled max-width content, desktop navigation and dashboard.
- Mobile: app-style viewport, large touch targets, bottom navigation, bottom-sheet authentication and single-column discovery.
- Real photography is sourced from Unsplash URLs; replace demo/profile imagery with licensed/owned assets before launch.
- Existing Supabase/auth/onboarding flow is preserved.

## Important

This is a front-end UX/UI pass. Production launch still requires final QA, real member data, storage policies, RLS, moderation, analytics and deployment checks.
